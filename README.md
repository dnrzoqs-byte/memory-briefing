# 반도체 브리핑

보유 6종목(삼성전자우·삼성전자·대덕전자·원익IPS·AMD·셀레스티카)의 대응 전략과 향후 전망을 중심으로, 메모리 사이클과 금리·환율·AI 투자 같은 대내외 변수를 한 화면에서 보는 개인 브리핑입니다.
주소: <https://dnrzoqs-byte.github.io/memory-briefing/>

모든 문장은 세 가지로 나눠 표시합니다.

- **사실**: 공시나 보도로 확인한 내용(출처 링크 포함)
- **전망**: 기관이나 회사가 내놓은 예상
- **판단**: 이 페이지의 해석

## 화면 구성

| 탭 | 내용 |
| --- | --- |

| 메모리 사이클 | 계약가 상승률 전망, 분기 영업이익, 시장이 가격에 넣은 배수, 메모리 3사 6개월 성과, DRAMeXchange 현물가와 기록, 정점 신호 점검, HBM 전망, SOX 역대 하락장 비교 |
| 내 종목 | 종목별 전략(이럴 때 이렇게, 2027년 강세·기본·약세, 다음 확인 일정), 1년 차트와 PER 기준선, 52주 범위, 수익률·변동성, 밸류에이션, 사실·보유 논리·점검 신호, 내 포트폴리오, 종목 간 상관계수 |

## 데이터 흐름

1. GitHub Actions와 PC 작업이 각각 `update_market_data.py`를 실행해 1년 일봉, 현물가, 신호를 만듭니다.
2. 수집에 실패한 항목은 직전 값을 유지하고 `stale` 표시를 남깁니다. 지어낸 기본값은 쓰지 않습니다.
3. D램 현물가와 스트레스 지수 기록은 원격 JSON과 합쳐서 쌓이므로 두 곳이 번갈아 실행해도 사라지지 않습니다.
4. 화면은 열릴 때 TradingView에서 시세를 바로 받습니다. 국내 종목은 20분, 미국 종목은 15분 지연이고 코스피·VIX·금리·환율은 실시간입니다. 장이 열린 날에는 1분마다 다시 받고, 국내 시간외·미국 장전·장후 가격도 함께 보여 줍니다.
5. TradingView가 실패한 종목은 CNBC 값을 쓰되, CNBC의 전일 종가가 서버 종가와 맞을 때만 받아들입니다. 둘 다 안 되면 서버 데이터를 그대로 씁니다.
6. `새로 고침` 버튼은 실시간 시세와 서버 데이터를 함께 다시 받습니다.

## 분석을 고칠 때

`data/research.json`만 고치면 됩니다. 다음 자동 실행 때 화면에 반영되고, 바로 보려면 아래를 실행합니다.

```powershell
python scripts/update_market_data.py
```

문장 안에 쓸 수 있는 표기는 다음과 같습니다.

- `==구절==`: 연한 형광펜 강조. 문단마다 한두 곳만 씁니다.
- `{{sox_dd}}`, `{{sec_x}}`, `{{hynix_x}}`, `{{disc}}`: 실시간 값으로 바뀝니다.
- `{{per:005930.KS|45565}}`: 현재가 ÷ 주당순이익. `{{yld:005935.KS|9433}}`: 주당 배당 ÷ 현재가.

종목별 전략은 `holdings.<종목>.strategy`에 있습니다. `call`(한 줄 방향), `tone`(hold·add·wait·trim), `line`(전략 문장), `plan`(이럴 때 `if`, 이렇게 `then`), `outlook`(강세·기본·약세)을 씁니다. 일정의 `for`에 종목 코드를 넣으면 그 종목의 다음 확인 일정으로 나옵니다.

`as_of`와 `version`을 올리면 열려 있는 화면도 새 분석을 다시 읽습니다.

## 카톡 자동 발송 (PC)

```powershell
python kakao_auth_setup.py        # 최초 1회 토큰 발급
.\register_schedule.ps1            # 12:00, 19:00 작업 등록
```

PC 작업은 로컬 폴더의 `assets`, `data`, `index.html`을 GitHub에 올립니다. 내용이 같은 파일은 건너뛰고, 화면 파일을 `index.html`보다 먼저 올립니다.
