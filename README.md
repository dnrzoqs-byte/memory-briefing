# 반도체 브리핑

메모리 사이클, 보유 6종목(삼성전자우·삼성전자·대덕전자·원익IPS·AMD·셀레스티카), 금리·환율·AI 투자 같은 대내외 변수를 한 화면에서 보는 개인 브리핑입니다.
주소: <https://dnrzoqs-byte.github.io/memory-briefing/>

모든 문장은 세 가지로 나눠 표시합니다.

- **사실**: 공시나 보도로 확인한 내용(출처 링크 포함)
- **전망**: 기관이나 회사가 내놓은 예상
- **판단**: 이 페이지의 해석

## 화면 구성

| 탭 | 내용 |
| --- | --- |
| 오늘 | 한 줄 판단과 근거, 할 일과 하지 않을 일, 시장 스트레스 지수(7개 신호), 시장 한눈에, 내 종목, 최근 3주 사건, 다가오는 일정, 2027년 시나리오 |
| 메모리 사이클 | 계약가 상승률 전망, 분기 영업이익, 시장이 가격에 넣은 배수, 메모리 3사 6개월 성과, DRAMeXchange 현물가와 기록, 정점 신호 점검, HBM 전망, SOX 역대 하락장 비교 |
| 내 종목 | 종목별 1년 차트와 기준선, 52주 범위, 수익률·변동성, 밸류에이션(우선주 할인율·배당 시나리오, 시총 배수, PER 가격대), 사실·논리·점검 신호·일정·뉴스, 내 포트폴리오, 종목 간 상관계수 |
| 대내외 변수 | 미국 금리와 연준 범위, 연준·한은, 원/달러, 신용 시장, 빅테크 투자, 엔비디아, 수출과 외국인 수급, 정책·공급, 변수별 영향 표 |
| 일정·뉴스 | D-day 일정, 분류별 뉴스, 출처 목록, 용어 |

보유 수량과 평균단가는 `내 종목 > 수량·단가 입력`에서 넣습니다. 값은 그 기기의 브라우저에만 저장되고, 코드 복사로 다른 기기에 옮길 수 있습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 틀. 업데이터가 `EMBEDDED_LIVE_PAYLOAD`, `EMBEDDED_RESEARCH` 마커 사이에 데이터를 넣습니다 |
| `assets/app.js`, `assets/app.css` | 화면 코드와 스타일(차트는 외부 라이브러리 없이 SVG로 그림) |
| `data/latest_briefing.json` | 자동 수집 데이터: 시세·1년 일봉, D램 현물가, 시장 스트레스 신호, 현물가·스트레스 기록, 뉴스 |
| `data/research.json` | 사람이 정리하는 분석: 판단, 사건, 사이클 자료, 종목별 사실·논리, 일정, 출처 |
| `scripts/update_market_data.py` | 수집기. Yahoo Finance, DRAMeXchange, Google News, FRED(접속될 때만) |
| `.github/workflows/daily_briefing_updater.yml` | 장중 30분, 그 밖에는 1시간마다 수집기 실행 |
| `fetch_and_send_kakao.py` | PC 작업(12:00, 19:00): 수집, 카톡 문구 작성, GitHub 업로드, 카톡 발송 (로컬 전용) |

## 데이터 흐름

1. GitHub Actions와 PC 작업이 각각 `update_market_data.py`를 실행합니다.
2. 수집에 실패한 항목은 직전 값을 유지하고 `stale` 표시를 남깁니다. 지어낸 기본값은 쓰지 않습니다.
3. D램 현물가와 스트레스 지수 기록은 원격 JSON과 합쳐서 쌓이므로 두 곳이 번갈아 실행해도 사라지지 않습니다.
4. 화면은 열릴 때 내장 데이터를 바로 그리고, 5분마다 `data/latest_briefing.json`을 다시 읽습니다. `시세 직접 조회` 버튼은 공개 프록시로 Yahoo 시세를 바로 가져옵니다.

## 분석을 고칠 때

`data/research.json`만 고치면 됩니다. 다음 자동 실행 때 화면에 반영되고, 바로 보려면 아래를 실행합니다.

```powershell
python scripts/update_market_data.py
```

판단 문장 안의 `{{sox_dd}}`, `{{sec_x}}`, `{{hynix_x}}`는 화면에서 실시간 값으로 바뀝니다. `as_of`와 `version`을 올리면 열려 있는 화면도 새 분석을 다시 읽습니다.

## 카톡 자동 발송 (PC)

```powershell
python kakao_auth_setup.py        # 최초 1회 토큰 발급
.\register_schedule.ps1            # 12:00, 19:00 작업 등록
```

PC 작업은 로컬 폴더의 `assets`, `data`, `index.html`을 GitHub에 올립니다. 내용이 같은 파일은 건너뛰고, 화면 파일을 `index.html`보다 먼저 올립니다.
